# Merge Readiness Standard

A lane may be described as merge-ready only when the current candidate and owning repository support that claim:

- Exact target branch and commit are rechecked against the PR and intended base.
- Relevant tests and release checks passed for that exact source; failures and skips are recorded.
- File scope, conflicts, and unrelated dirty work are identified and preserved.
- The installed canonical Selective Intelligence skill at `~/.agents/skills/selective-intelligence/SKILL.md` has been applied, including independent review when its current triggers select it.
- Required user, product, or human quorum authority is current and recorded.
- The next transition after merge, such as deployment or live verification, remains separately identified.

No named Gemini or Gawain pass is a standing prerequisite or merge instruction. A packet or model verdict cannot grant human approval. Recheck all material facts immediately before integration.
